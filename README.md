This repository contains my completed **Level 1** projects for the CodSoft Web Development Internship. All tasks were built from scratch using HTML, CSS, and Vanilla JavaScript.

* **Folder:** [`/CODSOFT_TASK1_PORTFOLIO`](./CODSOFT_TASK1_PORTFOLIO)

A modern landing page designed using CSS Flexbox and Grid with a focus on responsive layout structure.
* **Tech Stack:** HTML5, CSS3
* **Folder:** [`/CODSOFT_TASK2_LANDING PAGE`](./CODSOFT_TASK2_LANDING%20PAGE)

An interactive calculator that performs standard arithmetic operations with basic DOM manipulation and event handling.

* **Folder:** [`/CODSOFT_TASK3_Calculator`](./CODSOFT_TASK3_Calculator)
